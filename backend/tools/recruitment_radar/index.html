采集配置与本地 CLI

公开页面先直接读取；配置 Firecrawl / AnySearch 后自动补充抽取。服务端环境变量：RADAR_FIRECRAWL_API_KEY、ANYSEARCH_API_KEY；匿名 AnySearch 可设 RADAR_ANYSEARCH_ENABLED=1。本页不会使用上游内置共享密钥或公共代理。

BrowserAct / OpenCLI 需要你另外安装、登录及配置适配器，本站不自动执行本地命令，也不自动解验证码。运行后将岗位 JSON/CSV 导入即可；原仓库没有提供其文档中提到的 OpenCLI 校招适配器代码。
